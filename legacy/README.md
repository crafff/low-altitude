# 历史资料归档

本目录保存旧系统、实验资料及事故恢复记录，供新系统按需参考。归档不代表恢复了全部工作区，也不代表旧实验成功复现了论文。

- [2026-09-04 误删恢复归档](recovery-20260904/README.md)：已恢复文件、完整 Git 历史、未恢复清单和事故证据。
- [重建前半成品](pre-rebuild-20260904/README.md)：新系统重写前的源码/配置快照、退出活动路径的旧测试及baseline、旧角色配置。

旧规则和旧代码属于历史资料，不自动成为新系统的执行规则。不要直接运行归档中的测试、清理程序或实验入口；需要使用的代码应先单独检查，再移入隔离的开发环境。

这是同一物理磁盘上的本地归档，不是独立磁盘备份。

完整旧Git历史也保留在本地分支 `research/trc-reboot-20260904`。该历史中的两份约221MB文件被GitHub拒收，因此远端发布分支 `research/trc-baseline-system-20260905` 从新系统快照开始，不包含旧提交。新clone不能仅靠Git恢复本目录中的本地材料；重要长训练前还需独立介质备份。
