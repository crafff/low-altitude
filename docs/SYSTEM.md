# 一个简洁的科研工作循环

## 只保留一条主线

讨论问题 → 一个任务文件 → 小规模实现/运行 → 看结果与反例 → 更新任务和下一步。

任务只有 `todo / doing / done / blocked`。失败运行不会自动关闭任务；先记录原因，再决定修实现、调整假说或换实验。一个任务内可以连续多次DEV，不再拆出大量VAL/Run审批对象。`runs/`只是自动执行记录，不是额外科研对象。

## 多agent协作

主线程负责研究取舍、权限/预算、集成、运行和最终解释。仅在有可独立推进的具体工作时委派，角色按需选择，不要求每个任务凑齐多人。

| 角色 | 职责 | 边界 |
| --- | --- | --- |
| scholar | 原文、近邻、算法实现线索、假说及最小设计 | 只读，不执行项目代码 |
| builder | 一个明确模块或一组具体文件 | 保留其他人的改动，不跑实验、不清理、不改权限配置 |
| reviewer | 关键变更的安全/科研解释复核 | 只读，提出具体缺陷及最小修正，不制造审批链 |

三类角色全部Astra/xhigh；启动和模型核对规则以 [AGENTS](../AGENTS.md) 为准。角色配置约束未来加载，不能证明现有线程模型或操作系统权限。

交接仅五项：**问题、文件权限范围、已知事实链接、交付物、停止/预算条件**。返回只写：发现、证据、实际改动/验证、未解决问题、建议下一步。主线程将有用内容合并到对应任务/记忆，不要求每个agent写重复报告。

## 长期记忆与索引

| 文件 | 职责与更新时机 |
| --- | --- |
| paper/NOW.md + 当前任务 | 每次有实质进展或交接时更新；NOW只留最新结论、阻碍与下一步，细节留任务 |
| paper/PLAN.md | 目标、阶段或方法路线改变时更新，不抄运行记录 |
| paper/REPRODUCTION.md | 核实原文语义或确定重建参数时更新 |
| paper/LESSONS.md | 发现能用于后续工作的已确认教训时更新；同类教训合并 |
| paper/SOURCES.md | 新来源或来源改变判断时更新，保留链接、核验日期及未解决项 |
| paper/DECISIONS.md | 重大取舍时记录原因；任务内的小选择不重复登记 |

README、AGENTS和本页是稳定入口与规则，不承载当前进度。任务完成后保留为记录，由NOW指向下一任务；不定期翻新完成任务或按文件年龄造维护任务。新经验若已落实到代码/规则，LESSONS链接过去即可。

聊天记录是辅助线索，文件与原始产物才是跨线程接手依据。`lab search`即时搜索活动文档和代码，也包含README与AGENTS；不需要手动刷新索引，不搜索legacy、人类私人资料、模型或原始轨迹。`lab doctor`检查本地文档链接与NOW的任务入口；本地专有材料缺失单列提示，不冒充Git中已有备份。

doctor只检查活动文件中的普通内联Markdown路径，不请求外网、不验证锚点，也不是完整Markdown解析器。复杂链接语法仍需人工核对。

持续学习只做一件事：把已确认错误变成一条可执行经验和必要的回归测试。避免无证据归因、负结果消失、原文歧义被反复摘要后变成“事实”。

## 每次执行自动留下什么

```text
runs/<unique-id>/
  manifest.json   命令、源码/配置快照hash、资源边界、版本线索
  status.json     running → succeeded 或 failed
  log.txt         子进程输出
  source/         本次固定源码与显式输入；子进程只读
  artifacts/      子进程产物；沙箱内 /output
  scratch/        私有临时数据；沙箱内 /tmp
```

执行阶段标签为system/dev/train/eval/analysis，仅便于区分用途。源码快照比dirty Git HEAD更精确地描述实际执行内容；hash自动生成，不需要人工签名绑定。保存错误、超时和失败日志，不覆盖旧目录。

获授权的研究时段内，可以在已定范围与预算中自主查资料、实现、运行小测试和迭代；仅在权限缺失、明显扩大成本/范围或需要用户科学选择时停下来。具体授权与预算写在任务中，不从旧任务或本页推断。
