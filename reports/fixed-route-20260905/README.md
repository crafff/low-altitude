## 证据与审计口径

每架保留实际入场、完整所有poststep、计划/证书、原指标和终止状态。冲突由每步入场后的prestep位置计时；完整终止物理步同时计入航时、航程、越界和冲突，实际首次合格有限出口穿越后再删除。计划进度、实际最后航段投影/方向和误差管检查共同约束成功判定。超时与计划耗尽单列，提前耗尽的人口不赋公平联合风险比较标记。

[条件包含性定理](../../paper/LATERAL_EXECUTION_PROOF.md)适用于逐步通过证书的固定有限参考，其外部误差条件未变。额外两步续行覆盖实际出口可能略早/晚的情形，原出口没有移到参考步中点。它没有证明所有满足误差界的轨迹都在同一tick退出。通过实测误差检查不等于形式证明浮点程序的一致缺陷界。

名义组有7架实际退出早于参考1tick，其余353架同tick；左侧360架同tick，右侧1架早1tick、359架同tick。全部保留真实最后物理步，没有为了对齐参考而移出口或延迟删机。全程参考与实际误差及数值假设检查均通过；这些是这批有限轨迹的必要诊断，仍不是普适误差上界的证明。三臂均在实际入场初态下预先规划整条航程，尚未量测在线每5s重规划的可用吞吐或实时性。

[独立轨迹归约](../../src/fixed_route_audit.py)检查原case/flight/plan/trace完整覆盖，重算原始采样包含、航程、完整航时、实际首次合格出口，以及入场后prestep冲突；侧移同时重查至少20s保持、速度/航向和返回中心。该审计复用既有几何/风险函数，不称独立验证数值证书的外部假设。
