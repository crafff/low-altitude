## 明确的语义与限制

[实现与接口表](../../paper/REPRODUCTION.md#2026-09-05共享名义导航与动作反馈接口)。在reset入场前接入同一dispatcher，持续区分模型请求、下一物理步下发目标与实际TAS；不改写accepted action或效率成本。完成只解锁，继续保持目标；37是明确返回请求。速度可在横向/高度锁中改变。直接控制器的拒绝理由区分分量锁和已有末段后向CAP guard。

新增`info.execution_feedback`记录实际追踪与完成/越界；原7/10维网络观测和奖励保留，**没有直接的实际横向误差/边界余量特征，也没有越界罚项**。这些info不是模型输入，不据记录存在声称模型已经看到边界失败。CPA及机间安全仍用真实位置、速度/航迹和高度。

当前名义几何限速未认证CAP或偏移弯道，两个越界负结果保留。实验固定认证脚本的内收、强制回中、20s侧向保持和完整轨迹拒绝未加入baseline。实N_j方位恰好反向时，共享模式回退名义转角并记录次数以避免异常；最终原生两组次数均0，该边界分支由构造回归验证，不冒充实际机动证据。
