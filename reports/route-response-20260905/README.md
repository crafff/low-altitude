BlueSky 1.1.1 caches ordinary-flyby turn distance at route setup/waypoint advance, while its physical turning rate uses current TAS. The audited older [author fork reached implementation](https://github.com/RodolpheFmd/bluesky/blob/849d76fd44880f8d17a69aefa0bd37208f2b2fbb/bluesky/traffic/activewpdata.py#L84) recomputes the distance. The external refresh uses current TAS and current bearing, with radius `V²/(g tan(bank))` and distance `radius × abs(tan(course_change/2))`; it calls native reached exactly once and restores the facade afterward. It does not use the positive cached 1.1.1 turn-speed value for ordinary flyby.
