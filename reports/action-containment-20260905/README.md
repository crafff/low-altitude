# 固定动作执行与垂向离散证明

本轮将[条件推导](../../paper/CONTAINMENT_DERIVATION.md)对应到现共享BlueSky执行链。固定动作诊断与训练、随机场景评价分开；没有加载策略、训练模型或打开held-out。当前NR-only弯道限速未被移植进策略环境，也没有静默改变Table3、bank25、走廊宽高、动作档位、完成容差或退出统计。

## 预声明协议

使用`configs/paper_environment_execution_refresh.json`，每例一架F001/C01，从名义状态入场，t=5s发送一次绝对目标。等待用`step(None)`保持目标；目标速度误差≤0.001m/s、高度误差≤0.5m、横向误差≤2m、航迹角误差≤5°且两锁释放后，连续20s的0.25s观测均达标，才在允许的5s决策边界发送一次名义动作37。恢复后再保持20s，在下一个决策边界结束诊断。失配会重置保持时钟，未强制解锁或删除失败轨迹。

全矩阵1008例：12类×60目标的直道720例；12类×4速度×3lane×左右90°弯的名义高度288例。初测40例为Mavic/Amzn、直道两极速度/高度/侧向组合16例，加两极速度/3lane/镜像弯24例。所有航道总长5NM，弯道两段各4630m，纬度52°/经度4°原点；这是固定开发构造，不是1008个独立随机交通场景。

直道上限240模拟秒，弯道1200秒与原飞行期限相同。弯道必须已激活出段、物理位置在有限偏移出段上且目标/航迹达标，才能开始目标保持；在弯前恢复不算完成。自然到达、导航耗尽、超时与诊断截止分别记录；序列完成不等于全航程到达，原生到达也不等于完成了返回保持。该矩阵不覆盖任意初始状态、所有目标之间的直接切换、扰动或连续步内安全。

横向原始越界保留严格`distance >76.2m`，另列超过1μm/1mm/1m的时间帮助解释，不替换原指标。高度沿用原1μm评分容差。回调在原生更新及动作进度更新后、终止判断/删除前取样，保留完整终止步；逐例核对时间、越界、最大偏离和各阶段归并与原环境记录一致。

## 已完成的数学对应

[命题7](../../paper/CONTAINMENT_DERIVATION.md)直接使用当前垂向更新分支及settled锁：正常高度/VS=0初态下，每次升降单调位于旧高度与新目标之间；原生捕获直接赋目标高度，残余VS归零后才允许新高度。可达状态中0.05m/s的解锁条件蕴含VS精确为0，从而归纳保持76.2–137.16m。两名Astra分别源码推导与独立复核，无阻断。

该定理使用显式实数/六位量化假设，尚非编译浮点程序认证；也不是保持`dz/dt=VS`的连续运动证明。原生回放另记录实际解锁目标/VS与逐步单调性，以核对假设。当前垂向执行行为保持原样。
