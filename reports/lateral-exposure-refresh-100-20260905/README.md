## 解释边界与下一步

分类在`actions.update`之后、环境终止/删除之前采样，将整0.25s分配给末态。`lane_active`只表示控制器横移锁；capture只表示当前原生航点映射None，不是连续时间精确驻留，也不证明哪个机动导致越界。当前航点索引在LNAV关闭时仍可能保留；各首/峰/末样本同时保存LNAV、目标、锁、航点与真实状态。全局Python/NumPy/torch RNG逐回调核对不单独检查策略的私有采样generator；完整原链路与参考一致性提供进一步证据。没有宣称全物理轨迹逐点身份。

成功出口后整末步的保守贡献上界为`240×0.25=60s`，仅占原始越界量的0.128%，不足以解释大部分47057.5s。没有从统计中减去60s、删最后一步或声称连续出口前暴露已精确测量；该上界不覆盖其它积分/采样误差。

下一处值得核对的是横移命令后、人工捕获航点已切换时的实际跟踪与完成条件，尤其累计暴露较大的低速类型。先用已存样本定位可构造的固定响应，再考虑有针对性的诊断；本结果没有证明永久锁死或提出修改当前训练规则的因果依据。当前主线继续同科学配置训练。
