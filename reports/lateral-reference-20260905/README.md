# 横向有限执行：条件证明与原生重放

2026-09-05。本轮完成了一个**独立实验候选**的横向条件证明及原生重放。最终12机型144个构造性单机案例全部通过参考包含性、实际横向/高度、机动保持和有限退出检查。该结果没有证明旧45°CAP/miter执行器安全，也没有得到有效MARL基线。

## 方法与实际改变

BlueSky AP通过`selhdgcmd`每0.25s接收航向目标；native heading、TAS、位置更新仍实际运行，bank25°和Table3加减速不变。此API关闭LNAV，所以新候选自行保存有限计划及出口进度，没有接入会把LNAV-off判为耗尽的原PaperEnvironment。高度固定106.68m，无风/ASAS/噪声/延迟，无模型加载或训练。

请求lane为±76.2m，参考保持位置明确内收1m至±75.2m；这不是已确认作者设置。脚本在t5请求侧移、侧向保持至少20s、返回中心并保持至少20s；弯前回中且TAS按原生加减速降到`min(请求TAS,12m/s)`，出弯后固定脚本再次侧移/保持/返回。最终居中退出并保留整个物理末步。返回的是横向中心，直段速度仍为本案例请求档，不是原1008矩阵的完整action37恢复协议。侧向/中心保持误差分别按原2m/5°及速度0.001m/s容差独立检查。

最终矩阵为12机型×速度比0.5/1.05×两侧lane×直道/左90°/右90°，每机型12例，共144例；均有实际运动、完整固定脚本和真实出口穿越。只覆盖两端速度、固定高度及预定切换，不称全部60动作或任意策略覆盖。

这些是**构造性开发见证路线**：根据各机动的实际占用设置名义转角/航段长度，末端放在最后两个参考样本纵向中间，再重新认证。案例100–336.5sim秒，小于原1200s任务超时。它们不是原5NM开发场景、训练场景或held-out，不能据此声称原场景可行。内收、弯前/出口回中、连续限速、每物理步航向序列和不同终止构造均是显式新语义。

## 数学上得到什么

参考按原生先TAS、再heading、再latitude、最后用新latitude更新longitude的次序生成。每个heading命令用最坏TAS界验证转率可达；有限序列保留完整末步。证明递推每一步的位置误差箱，并要求相邻两误差球同时处于**同一有限名义航段**的capsule内。凸性覆盖整个位置线性插值，而不只检查采样点；纬度带比例处理原评分与固定原点投影的不同。

几何不等式使用精确有理数，三角函数界用有理数π包络/交错级数，误差每步向外量化到1e-12m网格。终止另检查所有此前误差箱在出口之前、最后误差箱在出口之后，且最后区间属于最终航段capsule；因此相同假设下首次合格穿越发生在最后物理区间。

条件包括：初始每轴位置误差≤1e-6m、纬度带51.8–52.2°、全程速度差≤0.0002m/s、实际与参考的实数位置更新残差绝对值之和每轴每步≤0.0001m、评分运算误差≤1e-6m，以及正确heading传递和执行模式。证明另从scalar/vector大气表达式推得固定高度CAS/TAS结构误差<0.0001275m/s，并用速度更新的非扩张性证明误差不因目标切换而逐步累加；剩余浮点运算预算仍未形式认证。

这些是明确的**条件保证**，不是整个NumPy/libm程序的无条件证书。原生重放检查观察到的速度/位置残差、heading取得和误差箱包含，但没有由最大实测误差反推普适上界。保证的步间曲线是存储位置的线性插值，不是未定义的连续物理盘旋轨迹。安全也不蕴含多机避碰、效率或所有动作都有可行计划。
