# 出口精度校准与1200/2400秒冻结对照

用户授权范围：先完成出口数值判定修正、冻结模型时限对照，不继续训练。原始12个已见DEV场景（53001–53012，360架次/组），无新held-out。108次完整对照和独立3240条飞行轨迹核算已完成；本轮没有训练或更新权重。建议下一轮训练把2400s作为显式模拟保护时限，原1200s配置保留为对照。

## 结果与结论

同一冻结256轮模型，每组原12场景、360架次。NMAC和LoWC均为无向pair-seconds；FH为所有到达/失败飞机的累计飞行小时。

1. **出口校准有效消除了微米级标签敏感性。** 256的新1200s剩余16次失败，出口偏离0.247651–26.193052m；新2400s剩余12次，范围相同，均非本次0.1mm容差能涵盖的微小残差。默认历史调用仍为1e-7m，只有共享环境显式使用新值。
2. **原53架超时慢机在2400s组全部到达。** 29 Mnet、24 Tecnalia实际用时1386.5–1673.75s，平均1547.09s。另4架由出口失败转到达，原291架到达均仍到达；这是完整交通重放后的结果，不能只把53补进原统计。中途曾据场景总失败数提出“慢机可能随后出口失败”，逐机审计已澄清本批53架全到达，剩余12失败来自其他飞机。
3. **2400s适合作为下一轮明确声明的保护时限。** 本任务聚焦局部冲突解脱，目前没有独立证据把1200s定义为业务硬截止；原文wall-time语义仍不确定。最慢机合法半速8.4kt走5NM的理想直道约2143s，2400s留出一定机动余量，但不保证任意策略/任意绕行都可完成。当前只在诊断副本比较，基础nr_pilot仍1200s，后续训练需显式建立2400s配置与新训练身份。
4. **更高完成率不是新学习收益，也没有消除效率代价。** 模型未训练。1200→2400的NMAC累计5332.5→5983.0，率80.20→83.58；LoWC累计上升而每FH率下降，不能把分母变化单独称安全改善。两组共有291架到达的航时差平均−0.113s、中位0；新增慢机使到达集合不同，全体到达平均565.80→717.73s不能直接解释为同一任务集整体变慢。2400s与NR的成功集合也不同；53慢机延长后的实际用时应单列。

出口校准下，初始/64/256（均1200s）到达297/298/291，NMAC率86.5582/73.8882/80.2024，仍不支持256持续优于64。348/360仅说明当前单个冻结模型在新2400s开发口径过95%完成门槛，不等于稳定有效基线、泛化或全程包含。下一步可在明确的新环境下从头进行分阶段训练，并保留未训练与NR对照；不把旧256轮曲线与新环境训练直接拼接。

## 事前协议

| 组 | 横向出口容差 | 每机模拟年龄限制 | 冻结策略 |
| --- | --- | --- | --- |
| old1200 | 1e-7m（0.1微米） | 1200s | 初始、64、256 |
| new1200 | 1e-4m（0.1毫米） | 1200s | 初始、64、256、NR |
| new2400 | 1e-4m（0.1毫米） | 2400s | 256、NR |

每组使用checkpoint内原样保存的几何、入场计划和12型性能，采样种子仍810000+场景seed。旧权重只用于冻结评价；不加载优化器续训、不改checkpoint、不绕过训练器兼容检查。旧模型训练环境和新评价环境分别保留来源。旧数值组须逐场景精确重现此前科学摘要和动作直方图；两NR组也须与原NR精确一致。1200/2400组在绝对模拟时间1200s以前的状态与动作摘要应一致。

0.1mm是明确的数值验收分辨率，远低于厘米及现有2m横向捕获容差；选择时已看过开发集诊断。它不证明微米级偏差全部来自浮点，也不是对完整积分/控制误差的数学上界。名义半宽76.2m、动作目标±76.2m、高度阈值、前进穿越/最终航段条件、奖励公式、动作控制器均保持。扩大的是出口标签的微小接受余量，原始严格越界统计不放宽；较大偏离仍失败。

时限仍从实际入场算起，以模拟秒计。2400s仅在诊断环境的场景配置副本中覆盖，reset会据此重建全局保护时长。原`nr_pilot.json`1200s不改。原文p.7 real-time120s与p.17 wall-time1200s存在口径歧义；本对照不宣称恢复作者的实现。

人口退出时间变化会改变后续相遇和随机数分配；相同场景与种子不等于逐机动作轨迹相同。因此不将旧失败直接重标为新成功，不把新增航时导致的每FH风险下降全部归因于冲突解脱。报告累计pair-seconds、flight-hours、每FH比率、实际任务时间/路径和逐机终态。
