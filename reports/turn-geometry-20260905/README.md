## 假设与距离

名义中心线为两条ray的并集：入射 `x <= 0, y = 0`，出射 `x = 0, y >= 0`。半宽 `w = 76.2m`；恒半径 `R > 0` 的精确切向四分之一圆连接已经建立的两条平行直线。右侧偏移为正，东转北时中心、内侧、外侧分别取 `d = 0, -w, +w`。定义 `a = 1 - 1/sqrt(2)`，圆弧为

```
x(theta) = d - R + R sin(theta)
y(theta) = R - d - R cos(theta), 0 <= theta <= pi/2.
```

入/出切点为 `(d-R,-d)`、`(d,R-d)`。到名义ray并集的距离在左上、左下、右上、右下四象限依次是 `min(-x,y)`、`-y`、`x`、`sqrt(x*x+y*y)`；不可在所有象限使用无限直线的最小距离。

推导不包含最初45°横移捕获、加减速、原生航点切换/跟踪误差、离散积分或出口之后的运动。有限航段长度 `L1,L2` 还须满足 `R-d <= min(L1,L2)`，保证切点位于任务航段之内。本例两段各4630m，所列三种半径满足该条件；出口后圆帽距离另作解释。

## 完整圆弧与直线接段的最大偏离

| 固定路径 | 最大距离 D | 在该理想模板下 D <= w 的条件 |
| --- | --- | --- |
| 中心 d=0 | aR | R <= (2+sqrt(2))w = 260.163073m |
| 内侧极限 d=-w | w+aR | 任意R>0均不满足 |
| 外侧极限 d=+w，0<R<w | sqrt(2)(w-aR) | 不满足 |
| 外侧极限，w<=R<=2w/a | w | 满足 |
| 外侧极限，R>2w/a | aR-w | 不满足 |

因此外侧模板的允许半径区间为 `[w,(4+2sqrt(2))w] = [76.2,520.326147]m`，小半径也可能在转角外侧圆帽处越界。

证明要点：中心/内侧圆弧位于左上象限，两个分支于theta=pi/4相交并达到最大值；直线接段的距离分别为0和w。外侧R<w时，圆弧位于右下象限，中点距离为上表首个外侧分支；直线越过原角点部分的最大值为 `J=sqrt(w*w+(w-R)^2)`，且 `D_mid^2-J^2=2(sqrt(2)-1)R(w-R)>0`，故中点仍控制全路径最大值。R>=w时需同时比较边缘接段w与左上象限圆弧峰值aR-w，后者仅在R>2w/a时更大。该比较避免把外侧中点一律误认为最大偏离位置。
